# 按键转换（input_remap）

把任意**物理**按键（键盘、鼠标按键、手柄按键）转换成另一种按键，一对一直替换。
典型用法：手柄按键 → 键盘按键 / 鼠标左键。

## 面板入口

「设备 → 参数配置 → 按键转换」。

- **启用转换**：总开关。关闭时规则保留但不生效。
- **添加转换**：添加一条规则，分别选「源按键」和「目标按键」。
- 选键与映射卡片一致：可以直接按一下设备上的键，也可以点「选择其它按键…」从完整键表里选。
- 修改后点弹窗底部的「保存」才会写入设备；「恢复默认」会清空全部转换规则。

## 效果

- 转换后**原按键不再触发**，目标按键按自己的类型继续工作（会参与映射开关、热键、
  映射引擎等，就像按下的是一个真实的目标按键）。
- 源按键与目标按键都不能重复；同一个源只能有一条规则。
- 只作用于物理输入。MAKCU 与 Lua 注入的按键不会被转换。
- 开启 MAKCU 协议时，上位机会把转换结果当作物理输入看到（例如手柄 A 转成鼠标左键后，
  `km.left()` 会返回按下）。
- 目标为键盘键时，如果要把它发送给电脑，需要同时开启「NKRO 键盘」，并在映射关闭的状态下
  才会直接转发给宿主。
- 手柄按键转换后，原来的手柄按键语义（包括映射开关组合键）不再由该键触发。
- 最多 64 条规则；格式错误的规则不会被写入设备。
