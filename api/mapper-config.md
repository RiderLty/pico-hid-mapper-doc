# 映射配置说明

本章节介绍 Web 配置面板（映射配置页）的全部功能与配置项。页面左侧为手机截图底图与映射控件，浮在上面的是可拖动的配置面板。

面板分三段，**上下两段常驻**，中间分四个分页切换：

| 位置 | 内容 |
| --- | --- |
| 顶部状态条 | 拖动面板（左侧把手）、未保存提醒、Pico 连接状态、日志/全屏按钮、收起面板 |
| 状态行 | 当前在做什么：「点击画布空白处添加映射」；选键弹窗打开时变成「正在选键 · 按一个键盘/手柄键即绑定」 |
| 分页 | **设备**（截图、存档、设备设置）· **映射**（映射开关按键、全部按键映射）· **屏幕**（分辨率、视角）· **轮盘**（中心半径、方向键、shift 疾跑） |
| 底部操作栏 | 配置名称输入、**更新**（写入槽位）、**导出**（下载 JSON） |

所有修改**先在页面内存中生效，点击底部的「更新」后才写入 Pico 的当前槽位**。

## 配置文件

配置文件为 JSON 格式，默认配置示例如下：

```json
{
  "SCREEN": {
    "SIZE": [3040, 1904, 3040, 1904]
  },
  "MOUSE": {
    "SWITCH_KEYS": ["KEY_GRAVE"],
    "RANGE": 0.05,
    "EDGE_RESET_ENABLE": true,
    "POS": [0.5936192468619247, 0.42093023255813955],
    "SPEED": [0.3, 0.3]
  },
  "WHEEL": {
    "POS": [0.15010460251046026, 0.6802325581395349],
    "RANGE": 0.06,
    "SHIFT_RANGE": 0.14,
    "RAND_RANGE": 0,
    "SHIFT_RANGE_ENABLE": true,
    "SHIFT_RANGE_SWITCH_ENABLE": true,
    "SHIFT_RANGE_SWITCH_KEEP_ENABLE": false,
    "WASD": ["KEY_W", "KEY_A", "KEY_S", "KEY_D"]
  },
  "KEY_MAPS": {
    "BTN_LEFT": {
      "TYPE": "AUTO_FIRE",
      "POS": [0.0653765690376569, 0.1325581395348837, 0.053],
      "INTERVAL": [18, 20]
    },
    "BTN_RIGHT": {
      "TYPE": "PRESS",
      "POS": [0.9513598326359832, 0.10465116279069768, 0.038]
    }
  },
  "IMG": ""
}
```

### 字段说明

| 字段 | 含义 |
| --- | --- |
| `SCREEN.SIZE` | 屏幕宽度、屏幕高度、外接显示器宽度、外接显示器高度。 |
| `MOUSE.SWITCH_KEYS` | 用于切换映射开关的按键，最多可设置四个。 |
| `MOUSE.RANGE` | 开始映射时，鼠标在该半径范围内随机选择坐标作为视角映射起点。 |
| `MOUSE.POS` | 鼠标视角映射的起始坐标，按屏幕宽度比例计算。 |
| `MOUSE.SPEED` | 鼠标 X、Y 轴的灵敏度缩放比例。 |
| `MOUSE.EDGE_RESET_ENABLE` | 视角拖动超出屏幕边界、重置回起始位置时的触点释放方式：`true` 交替释放（新旧触点短暂并存，模拟双手交替滑动），`false` 单点释放。 |
| `WHEEL.POS` | WASD 映射轮盘的中心位置。 |
| `WHEEL.RANGE` | WASD 轮盘半径。 |
| `WHEEL.SHIFT_RANGE` | 疾跑状态下的 WASD 轮盘半径。 |
| `WHEEL.RAND_RANGE` | 轮盘触点初始位置的随机半径（按屏幕宽度比例），`0` 表示不随机。 |
| `WHEEL.SHIFT_RANGE_ENABLE` | 是否启用 Shift 疾跑模式。 |
| `WHEEL.SHIFT_RANGE_SWITCH_ENABLE` | 疾跑切换方式：`true` 表示点击开启、再点击关闭；`false` 表示按住开启、松开关闭。 |
| `WHEEL.SHIFT_RANGE_SWITCH_KEEP_ENABLE` | 仅疾跑切换方式有效：`true` 表示松开 WASD 后保持疾跑状态（下次按下仍以疾跑半径起步）；`false` 表示松开 WASD 自动取消疾跑。 |
| `WHEEL.WASD` | 控制轮盘的四个方向键，顺序固定 = 上、左、下、右（默认 `["KEY_W", "KEY_A", "KEY_S", "KEY_D"]`）。可改成任意键盘按键（例如改成 `["KEY_E", "KEY_S", "KEY_D", "KEY_F"]` 即 ESDF 布局）。 |
| `IMG` | 截图的 base64 字符串。存储到 PICO 时会丢失，前端导出 JSON 时会保留。 |
| `KEY_MAPS` | 按键映射字典。 |

> 说明：所有浮点类型坐标均按屏幕宽度比例计算，实际坐标值为 `浮点值 × screenWidth`。

## 基本操作

### 上传截图

1. 在游戏界面截图（分辨率为手机实际分辨率）。
2. 在面板「**设备**」分页点击「上传截图」选择图片。截图加载后会自动把屏幕尺寸设置为截图的实际宽高，并进入全屏方便编辑。

> 截图只是编辑底图，用于精确定位触屏坐标，不会保存到 Pico（`IMG` 字段在写入槽位时丢弃）。重新打开页面时，若槽位配置无截图会生成纯蓝占位背景，重新上传即可。

### 放置按键映射

**先点位置，再选键**——点击截图上的空白位置，会在点击处弹出「添加映射」面板，面板标题栏里的坐标就是这次要放置的落点：

- **按一下键即可**（最快）：弹窗打开时直接按键盘上的某个键、或按手柄上的某个按键，映射立刻绑定到这个位置（弹窗顶部有这条提示）。
- **点选**：弹窗里有鼠标键快捷按钮（左 / 中 / 右 / 前 / 后 / 轮上 / 轮下，滚轮键固定使用「单次点击」类型），以及「选择其它按键…」按钮 —— 点开是**按键选择面板**：按鼠标 / 键盘 / 手柄分组的列表、每行显示中文名与原始键名，顶部搜索框可用中文名、`KEY_W` 或裸名 `W` 过滤；点某一行即选中。
- **一个键只能有一条映射**：如果这个键已经有映射，弹窗会提示并保持打开，不会覆盖原来的那条。
- 弹窗在点击处打开；继续点击画布可把它移到新位置，点画布以外、按 `Esc` 或点 ✕ 关闭。

放置之后：

- 触摸点可**拖动**调整位置；触摸点处于选中状态时**滚动滚轮**调整作用半径（每次点击的落点在半径内随机，模拟真人操作）。
- 点击触摸点会弹出编辑面板：可修改按键、类型与各项参数，面板内还有「屏幕取点」按钮（点击后直接在截图上点选新坐标）；按住面板顶部标题栏可拖动面板位置，点击面板外或 ✕ 关闭。
- 编辑面板与「**映射**」分页里的按键卡片内容一致，两处都能改按键、类型或删除：
  - **改按键**：点按键按钮打开**按键选择面板**（分组列表 + 搜索框，可搜中文名 / `KEY_W` / 裸名 `W`），点一行即改；也可以点右侧的键盘图标按钮后**直接按一下要换成的键**（键盘或手柄，`Esc` 取消）。换成已有映射的键会被拒绝并提示（列表里也不会出现已经用掉的键）。
  - **删除**：点右侧 ✕。

### 受浏览器限制的按键

部分按键在浏览器里无法捕获或映射不准确，例如 `ESC`、`CapsLock`。可以先用其他键创建，再在编辑面板/按键卡片的下拉框里改选目标按键（下拉框可搜索）；或将键盘单独接在 Pico 的 Host 口上——此时由 Pico 读取按键事件并经 WebSocket 转发到前端，可映射全部按键，也能直接用「按一下」的方式捕获。

## 按键类型

每个按键映射可选择以下类型（与页面类型下拉一致）：

| 类型 | 参数 | 说明 |
| --- | --- | --- |
| 同步按下释放 | 坐标 | 按键按下时触摸点按下，按键松开时触摸点释放。 |
| 切换按下释放 | 坐标 | 按键第一次按下时按下触摸点并保持，再次按下时释放；按键松开无响应。适合开关型操作（如开镜/收镜、开关面板）。 |
| 快捷轮盘 | 坐标、松开后关闭映射 | 按下时按下对应位置的触摸点，此时鼠标可以控制此触摸点，松开后释放。可用于轮盘选择物品、小眼睛观察等场景。<br>「松开后关闭映射」开关：开启后，松开该按键会关闭整个映射、切回虚拟光标（与切换热键关闭映射的效果一致）。 |
| 光标智能切换 | 两个触点、两个二选一、一个开关 | 具有两个触摸点，以及两组"二选一"选择（分段按钮，当前生效的一项高亮）与一个开关：<br>• **释放光标方式**：「按住-松开」（按住时释放光标、松开继续映射）或「点击-再点击」（点一下释放、再点一下继续映射）；<br>• **点击行为**：「点击并释放」（依次点击两个触点）或「仅释放光标」；<br>• **释放光标**（开关）：触发时是否退出映射、切换为光标模式。<br>可用于打开/关闭地图和背包、临时释放光标等场景。触点 0/1 均可通过「重设」在截图上重新点选。 |
| 单次点击 | 点击时间 (ms) | 仅响应按键按下，在指定位置按下触摸点，经过设置的延迟后释放。 |
| 连发 | 点击时长、间隔 (ms) | 按住按键期间，按照设置的点击时长与间隔，反复执行触摸按下与松开。 |
| 滑动 | 间隔 (ms)、关键点列表 | 按下时触摸点按照设置的关键点，依据设定的延迟依次滑动，并在终点停留；按键松开则释放触摸点。通过「添加关键点」在截图上逐个点选。 |
| 多点触摸 | 触摸点列表 | 按下时依次按下设置的触摸点，按键松开时依次释放。通过「添加触摸点」逐个点选。 |

> 切换类型时会尽量保留已设置的坐标：多点类型转单点取第一个触点，单点转多点以原位置作为第一个触点。

## 屏幕与视角

### 屏幕尺寸 / 外接屏幕

都在「**屏幕**」分页的「屏幕尺寸」一组里：

- **实际分辨率**：手机实际分辨率。上传截图后自动填充，一般无需手改。
- **外接屏幕**：安卓设备外接显示器（或采集卡）时的显示器分辨率，详见下文[外接显示器](#外接显示器)。

### 视角（鼠标控制）

| 配置项 | 说明 |
| --- | --- |
| 灵敏度（横向 / 纵向） | 鼠标移动转成视角滑动的缩放比例，`MOUSE.SPEED`。 |
| 中心位置 | 开始映射时视角触点的落点，`MOUSE.POS`（只显示数值）。可在截图上直接拖动视角图标调整。 |
| 随机范围 | 开始映射时在中心附近随机取点的半径（像素），`MOUSE.RANGE`（只显示数值）。可在截图上滚轮调整，或拖动视角图标外圈。 |
| 越界释放方式（交替 / 单点） | 视角拖出屏幕边界、重置回起始位置时的触点释放方式（`MOUSE.EDGE_RESET_ENABLE`），两个模式二选一。交替更接近真人双手交替滑动，单点则直接抬起再按。 |

## WASD 轮盘

轮盘用于把四个方向键（或手柄左摇杆）映射为游戏虚拟摇杆。都在「**轮盘**」分页里，分三组：中心与半径 / 方向键 / shift 疾跑（开关键右侧的小药丸显示当前状态）：

| 配置项 | 说明 |
| --- | --- |
| 中心位置 / 半径 | 轮盘触点的中心与移动半径（只显示数值）。可在截图上拖动轮盘、滚轮调整半径。 |
| 轮盘方向键 | 控制上 / 左 / 下 / 右四个方向的键盘按键（`WHEEL.WASD`，默认 W / A / S / D）。四个按钮按键盘 WASD 的键位排列（上排在中间，下排是左 / 下 / 右）：点击某个方向后按下一个**键盘**按键即可设置，Esc 取消。**只支持键盘按键**——按下鼠标键、滚轮或手柄键会提示不支持并退出设置；同一个键不能给两个方向。想用 ESDF 布局就把这四项改成 E / S / D / F。 |
| shift 轮盘（已启用 / 已禁用） | 是否启用疾跑外环（`WHEEL.SHIFT_RANGE_ENABLE`）。 |
| 疾跑触发方式（长按 / 切换） | 疾跑触发方式（`WHEEL.SHIFT_RANGE_SWITCH_ENABLE`），两个模式二选一：长按＝按住疾跑键才生效；切换＝点一下切换疾跑状态。 |
| 松开方向键后（保持 / 重置） | 仅切换模式下显示（`WHEEL.SHIFT_RANGE_SWITCH_KEEP_ENABLE`），二选一：松开方向键后保持疾跑，或回到走路半径。 |
| 疾跑 / 静步（常规 / 互换） | 仅启用 shift 轮盘时显示（`WHEEL.SHIFT_RANGE_SWAP_ENABLE`），二选一：互换＝默认疾跑、按疾跑键变静步。 |

> 上述"二选一"在面板上用**分段按钮**表示（两个选项并排、当前生效的高亮），而不是开关——开关的语义是"开/关"，表达不了"A 模式 / B 模式"。真正的开/关（如「shift 轮盘」是否启用、「释放光标」是否退出映射）仍用开关。
| 疾跑半径 | 疾跑外环半径的滑条（`WHEEL.SHIFT_RANGE`），仅启用 shift 轮盘时显示。 |
| 初始位置随机范围 | 滑条，每次开启映射时轮盘触点从配置中心附近随机位置开始（半透明圆显示范围，`WHEEL.RAND_RANGE`）；0 表示固定中心。 |

> 打开「参数配置」中的「随机轮盘」开关（默认开启）时，轮盘按神经网络轨迹 + 随机抖动移动，行为更拟人；关闭后进入**直连模式**：无轨迹与随机，按下方向键触点直接移动到对应方向位置。轨迹细节（精细度、速度、抖动等）在「轮盘参数」弹窗中调整。

## 映射切换按键

- 切换键用于在**映射模式**与**虚拟光标模式**间开关映射（默认 `` ` `` 键）。
- 点击「添加映射切换键」后按下一个键盘按键即可添加（也支持 Pico Host 口直连键盘的按键事件）；重复添加会提示已存在。点击已添加的按键名可删除。最多 4 个。
- 槽位热键 `Left Alt + F1~F9` 与切换键独立：Alt 系列切槽位，切换键开关映射。

---

> 面板里的弹窗与分页共用同一套视觉语言：设置项按「分组卡片 + 设置行」排列，**在两个模式之间选一个**用分段按钮（当前生效的高亮），真正的开/关用开关（右侧带「已开启 / 已关闭」状态）。操作结果与错误都在弹窗标题右侧以状态药丸或行内提示条给出，不使用会阻塞页面的弹出框（`alert` / `confirm`）。

## 槽位管理

在「**设备**」分页点击「选择槽位」打开配置槽位管理，共 9 个槽位（编号 0–8，热键 F1 = 槽 0）：

- **编辑此配置 / 在此槽位新建配置**：把该槽位内容加载到编辑器（编辑中标记）。
- **使用此配置**：将设备切换为使用该槽位（使用中标记）。
- **设为默认**：设备重启后默认使用的槽位（默认标记）。
- **删除**：清空该槽位。删除是**卡片内二次确认**（点「删除」后卡片里出现「确认删除 / 取消」，不再弹浏览器确认框——浏览器确认框会阻塞整个页面）。
- 未激活设备只能使用槽位 0，槽位 1–8 显示锁定，激活后可用。

底部「更新」按钮把当前编辑器内容写入**当前选中的槽位**（需先用槽位弹窗选择，否则会提示）；它只写入不切换，「使用此配置」才改变设备正在运行的配置。「导出」按钮把当前配置（含截图）下载为 JSON 文件。

## 参数配置弹窗

「**设备**」分页里的「参数配置」打开的设置独立于映射 JSON，保存在设备存储中，点「保存」后立即生效，「恢复默认」还原全部默认值：

| 配置项 | 说明 |
| --- | --- |
| 光标显示方式 | 光标怎么画：虚拟光标（默认，需装安卓端 app）/ 空心环（免 app，需打开系统「显示点按操作反馈」）/ 触摸笔（系统原生笔形光标）/ 直接鼠标（以 USB 鼠标方式输出，苹果安卓通用）。**切换需重启设备后生效**。 |
| 键盘直通 | 映射关闭时，插在设备上的键盘直接在手机/电脑上打字。**切换需重启设备后生效**。 |
| 随机轮盘 | 开启：WASD 轮盘走神经网络轨迹 + 随机抖动（拟人化，默认）。关闭：直连模式，按下直接落位到方向半径处，无中间轨迹、无随机。 |
| 疾跑键 | 触发疾跑的按键，默认不修改（Shift）。点击按钮后按下任意键盘按键选择，Esc 取消，「重置」恢复 Shift。 |
| 光标显示位置 | 虚拟光标由隐藏切换为显示时强制移动到此坐标（屏幕像素）。`0,0` = 不重置（保持当前位置）。可点击「在屏幕点选」直接在截图上选位置。 |
| 鼠标速度 | 鼠标移动速度倍率，`0` = 不调整（默认），`1.0` = 原始速度。 |
| 滚轮速度 | 一格滚轮折算的屏幕像素，`0` = 默认（64）。 |
| 视角自动释放超时 | 视角模式下停止输入后自动松开视角的时间（毫秒），`0` = 默认（400），负数 = 永不自动释放。 |

> 「ESDF 方向键」开关**已弃用并从面板移除**：它以前做的事（把轮盘方向键从 W/A/S/D 换成 E/S/D/F）现在由映射配置里的「轮盘方向键」（`WHEEL.WASD`）直接完成——在[WASD 轮盘](#wasd-轮盘)区把那四项改成 E/S/D/F 即得到原来的 ESDF 布局。旧版本留下的开关状态在保存配置时原样保留，不会影响使用。

「轮盘参数」（设备分页）调整随机轮盘的轨迹手感（直连模式下不生效），同样支持「恢复默认 / 刷新 / 保存」：

## 外接显示器

当安卓设备外接显示器（或采集卡）时外接 USB 触摸屏将绑定到外接显示器，会导致以下问题：

- 按键位置错乱
- 屏幕旋转方向失效

针对屏幕旋转方向错乱，需要在`PICO 系统配置`-`屏幕旋转方向`中将旋转方向手动设置为 `0`。

分辨率设置分为以下三种情况：

* **直接镜像**  
   安卓画面等比例显示在外接显示器上，左右或上下可能出现黑边。此时截图分辨率应使用安卓原生屏幕截图分辨率，外接显示器分辨率设置为外接显示器的实际分辨率。

* **`wm size` 后镜像（推荐）**  
   使用 `wm size` 指令将安卓原生屏幕分辨率设置为与外接显示器分辨率相同后再镜像。此时使用 `wm size` 修改分辨率后的截图创建设置，外接显示器分辨率无需修改，保持与截图相同。

* **扩展显示**  
   安卓设备与外接显示器独立显示画面，互不干扰。此时使用外接显示器上的游戏画面截图创建设置，外接显示器分辨率无需修改，保持与截图相同。
