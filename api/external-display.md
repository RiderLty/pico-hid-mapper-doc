# 外接显示器 / 采集卡

当安卓设备外接显示器（或采集卡）时，外接 USB 触摸屏会绑定到外接显示器，映射的触控坐标系随之变化，可能出现：

- 按键位置错乱
- 屏幕旋转方向失效

## 屏幕尺寸

在「**屏幕**」分页的「屏幕尺寸」一组：

- **实际分辨率**：手机实际分辨率。上传截图后自动填充，一般无需手改。
- **外接屏幕**：外接显示器（或采集卡）的显示器分辨率。

## 旋转方向

外接显示器时系统无法自动识别方向。

- **已开启虚拟光标（vPointer）**：检测到外接显示器后，虚拟光标会始终上报方向 0°，一般不需要手动调整。
- **方向仍然错乱**：在「**PICO 配置 → 屏幕旋转方向**」中手动设为 **0°**。

## 分辨率与截图设置

按画面显示方式选择：

### 直接镜像

安卓画面等比例显示在外接显示器上，左右或上下可能出现黑边。

- **截图分辨率**：使用安卓原生屏幕截图分辨率
- **外接显示器分辨率**：填外接显示器的实际分辨率

### wm size 后镜像（推荐）

使用 `wm size` 将安卓原生屏幕分辨率设置为与外接显示器分辨率相同后再镜像。

- **截图分辨率**：使用 `wm size` 修改后的分辨率
- **外接显示器分辨率**：无需修改，保持与截图相同

### 扩展显示

安卓设备与外接显示器独立显示画面，互不干扰。

- **截图分辨率**：使用外接显示器上的游戏画面截图
- **外接显示器分辨率**：无需修改，保持与截图相同

## 采集卡

采集卡等同于外接显示器，画面比例通常为 **16:9**，**外接屏幕**填 `1920×1080` 即可。
